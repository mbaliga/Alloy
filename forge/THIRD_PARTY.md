# Third-party components

Alloy Forge is covered by the repository licence (PolyForm Noncommercial 1.0.0, see `../LICENSE`). It bundles or loads these components, which keep their own licences:

| Component | Licence | How it is used |
|---|---|---|
| [three.js](https://github.com/mrdoob/three.js) | MIT | 3D viewport, orbit and transform controls; bundled into `app.js` |
| [Manifold](https://github.com/elalish/manifold) (`manifold-3d`) | Apache-2.0 | Mesh boolean kernel (WASM); bundled into `app.js` |
| [occt-import-js](https://github.com/kovacsv/occt-import-js) | LGPL-2.1 (wraps Open CASCADE, LGPL-2.1 with exception) | STEP reader, loaded at runtime as a separate, unmodified `occt-import-js.js` + `.wasm`; `build.mjs` copies its licence to `dist/LICENSE.occt-import-js.txt` |
| [replicad](https://github.com/sgenoud/replicad) | MIT | B-rep modelling API over Open CASCADE (lofts, booleans, fillets, STEP export); bundled into `occt-worker.js`, the lazy-loaded OCCT kernel worker |
| [replicad-opencascadejs](https://github.com/sgenoud/replicad/tree/main/packages/replicad-opencascadejs) | LGPL-2.1 (a custom Open CASCADE build; Open CASCADE is LGPL-2.1 with exception) | The B-rep kernel for the OCCT path. Shipped **unmodified and as separate files**, `occt/replicad_single.js` (Emscripten loader) + `occt/replicad_single.wasm`, which `occt-worker.js` fetches at runtime on first use; it is not bundled into any of this project's JavaScript. `build.mjs` copies its licence to `dist/occt/LICENSE.replicad-opencascadejs.txt`. **LGPL replaceability:** to use your own build of Open CASCADE, replace those two files with a compatible replicad-opencascadejs build (same Emscripten module interface) and reload; no rebuild of Forge is needed |
| [d3-delaunay](https://github.com/d3/d3-delaunay) | ISC | Voronoi cells for the cell texture of the PCB enclosure template; bundled into `occt-worker.js` |
| [esbuild](https://github.com/evanw/esbuild) | MIT | Build tool only, not shipped |
| Loop engine (`src/loop/`) | Same as this repository (PolyForm Noncommercial 1.0.0), own work vendored from `mbaliga/Shared-Libraries-asoc` `web/loop-engine` | Runs the design loop graph; source commit in each file header and `src/loop/VENDORED.md`. A dependency-free port of the Fonebrew loop engine semantics |
| Loop schema and spec concepts | Fonebrew (`mbaliga/android-ide-core`), `LICENSE-PENDING` upstream | `loops/enclosure-design.loop.json` follows the Loop Definition v2 schema; the schemas are embedded in the vendored engine (`src/loop/schemas.js`). Licence to be confirmed before any redistribution outside this repository |
| Extension host (`src/ext/`), sample packages (`examples/ext/`) | Same as this repository (PolyForm Noncommercial 1.0.0), own work | Package loader, manifest validator, permission-checked API, Worker host, pane bridge, overlay renderer. **No new third-party dependency**: the zip reader/writer and the JSON Schema validator are written in-tree; deflate uses the browser's/Node's built-in `DecompressionStream` / `CompressionStream`, and hashing uses Web Crypto. Packages a user installs keep their own licences (shown in the install prompt) and are not part of Forge. |
| Analysis framework (`src/analysis/`), `analysis/materials.json`, `analysis-validation/`, `examples/ext/sample-mass` | Same as this repository (PolyForm Noncommercial 1.0.0), own work | **No new code dependency.** The material values are typical figures compiled from the public datasheets and references cited per value inside `materials.json` (facts, not copied text); they are not measurements and many are marked `estimate`. |
| `examples/ext/thermal-estimate` (A1) | Same as this repository (PolyForm Noncommercial 1.0.0), own work | **No new code dependency.** The correlations are standard published engineering formulas (Churchill and Chu 1975; the horizontal-plate and flat-plate forms in Incropera and DeWitt and in Cengel), re-implemented from their formulas; the validation cases cite the worked examples they were checked against and use only the numbers, not the text. |
| `analysis/voxel-core`, `analysis/thermal-3d`, `examples/ext/thermal-3d` (A2) | Same as this repository (PolyForm Noncommercial 1.0.0), own work | **No new dependency.** Plain JS typed arrays and WGSL compute shaders written for this repository (a Jacobi-preconditioned conjugate gradient and a finite-volume stencil are textbook methods). The triangle/box overlap test is the standard separating-axis construction (Akenine-Moller, 2001), re-implemented from the published method. The convection and radiation correlations are copies of A1's (see above). `examples/ext/thermal-3d/main.js` is generated by `tools/bundle-ext.mjs` from those sources. |
| `analysis/structural`, `examples/ext/structural`, `analysis/voxel-core/elastic.js`, `analysis/voxel-core/gpu-elastic.js` (A3) | Same as this repository (PolyForm Noncommercial 1.0.0), own work | **No new dependency.** The 8-node hexahedron with incompatible (bubble) modes is the textbook element (Wilson, Taylor, Doherty and Ghaboussi 1973; Taylor, Beresford and Wilson 1976), re-implemented from the published method with the modes condensed out; the matrix-free Jacobi-preconditioned conjugate gradient is a textbook method; the stress recovery is a local linear least-squares fit in the spirit of Zienkiewicz and Zhu's superconvergent patch recovery. The validation cases cite Gere and Goodno (beam and bar formulas), Timoshenko and Goodier (Kirsch) and Peterson/Roark (the finite-width stress concentration polynomial, recalled and not re-checked against the books) and use only the formulas and numbers. `examples/ext/structural/main.js` is generated by `tools/bundle-ext.mjs`. No code was taken from Elmer, CalculiX, OpenFOAM or any other solver. |
| `analysis/runner`, `examples/ext/runner`, `src/analysis/runner-client.js`, `tools/make-reference.mjs` (A4, Forge side) | Same as this repository (PolyForm Noncommercial 1.0.0), own work | **No new dependency, and no GPL code in Forge.** The package only sends HTTP requests (through the host) to an Alloy Runner the user runs. The runner (`../runner/`) starts **gmsh (GPL), Elmer (GPL/LGPL) and, later, OpenFOAM (GPL) as separate processes** inside its own container; nothing of them is linked into, bundled with or copied into Forge or this repository. See `../runner/THIRD_PARTY.md`. |
